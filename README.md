## 💻 Sintaxe do código

👩‍💻 **A estrutura de decisão match**, compara o valor da variável **status** com os valores especificados nos casos **(case)**.

---

## ⚙️ Instruções da execução do sistema

- O programa utiliza a estrutura de decisão match:case para verificar o status do atendimento técnico informado pelo usuário.
- Dependendo do status informado, o programa exibirá uma mensagem informativa ao usuário.
